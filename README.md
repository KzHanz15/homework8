## 运行方法

两个子项目均为纯静态前端，需本地 HTTP 服务器运行（fetch 加载本地 JSON 会被浏览器拦截在 file:// 下）：

```bash
# 从仓库根目录
python -m http.server 8080
# 打开 http://127.0.0.1:8080/integration/  或  http://127.0.0.1:8080/activity-center/
```

更详细的运行与资源来源说明见各自子目录的 README。
